# NotebookLM Analysis Templates

Templates for outputs generated by the `notebooklm-analysis` method.

## Templates

- [[01-source-summary]] — one file per newly detected source
- [[02-incremental-insights]] — one file per update batch
- [[03-trend-impact]] — one file per update batch
- [[04-question-backlog]] — one file per update batch
- [[05-concept-map-delta]] — one file per update batch

## Naming Rule

For a single new source, all five output files should share the same prefix:

```text
[YYYY-MM-DD]-[source-slug]-[source-id-short]
```

For a multi-source update batch, use:

```text
[YYYY-MM-DD]-multi-source-update
```
